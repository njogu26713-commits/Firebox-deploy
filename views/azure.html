Azure Service Principal
Connect a Microsoft Azure account using a Service Principal (App Registration). FireboxDeploy uses these credentials to deploy and manage resources on your behalf.
Unconfigured
How to create a Service Principal
  1. In the Azure Portal, go to Azure Active Directory → App registrations → New registration.
  2. Give it a name (e.g. firebox-deploy), then click Register.
  3. Copy the Application (client) ID and Directory (tenant) ID from the overview.
  4. Under Certificates & secrets → New client secret, create a secret and copy its Value.
  5. Go to your Subscription → Access control (IAM) → Add role assignment and assign the Contributor role to the app registration.
  6. Copy your Subscription ID from the Subscription overview.
